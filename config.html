Event Configuration

This private link is limited to this event. It does not provide access to vouchers, guest records, payments, gate tools, or other events.

1. Event Information & Ticket Tiers

Use the Google Form below. The Event ID and security key are already filled in for you. You may create up to 12 tiers in the form; leave unused tier sections blank. Tier colors are optional. If you leave a color blank, the ticketing system assigns a coordinated default automatically.

Open Form in New Window

2. Branding

Upload your organization/event logo and an optional background image. The logo is also used as a large faint ticket watermark. The QR safe zone remains solid white for reliable scanning.

3. Ticket Preview

After submitting the Google Form, tap Load Ticket Preview. This uses the same ticket renderer as real vouchers. The preview QR and serial are samples and cannot be used for admission.

4. Review & Approval

If you want changes, edit and resubmit the Google Form above, then reload the preview. Approve only when the event information, pricing, colors, logo, and layout are correct.
